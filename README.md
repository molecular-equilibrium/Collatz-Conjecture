# Collatz Conjecture:
# This program simply attempts to explore the sequence
# associated with the Collatz conjecture. To this day it
# has not been proven to be false, as it is a one of many
# biggest problems within mathematics.

# What is the conjecture about:
# The Collatz conjecture is a mathematical hypothesis that states 
# for any number, it will eventually reach down to the number one
# using a sequence followed by a given set of rules.

# If the number is even, divide by 2.
# If the number is odd, multiply 3 and add 1.
# The sequence will eventually reach 1 according
# to the hypothesis, but no one has yet to disprove
# the hypothesis.
